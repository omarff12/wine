# CryptoVerse

CryptoVerse is a decentralized platform designed for cryptocurrency trading, staking, NFT marketplace, and community governance.

## Features

- **Staking**: Stake CVToken and earn rewards.
- **NFT Marketplace**: Buy, sell, and mint NFTs.
- **Governance**: Vote on proposals using CVTokens.
